# Security Policy

## Supported Versions

The latest release on the `main` branch receives security fixes. Tagged
releases are patched for the most recent minor version.

| Version | Supported |
| --- | --- |
| latest release | ✅ |
| older releases | ❌ |

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, report them privately by opening a security advisory at:

https://github.com/RAVEYUS/k8-ctx-dumper/security/advisories/new

You will receive an acknowledgement within 3 business days, and we will keep
you updated on the fix and disclosure timeline.

## Security Practices

This repository participates in the [OpenSSF Scorecard](https://securityscorecards.dev/)
supply-chain security assessment. Results are published to the repository's
security dashboard after each run of the Scorecard workflow.

Dependencies are tracked by Dependabot, which opens pull requests for both Go
module and GitHub Actions updates on a weekly schedule.
